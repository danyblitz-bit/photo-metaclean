Audit Hidden Metadata

A smartphone photo can reveal your exact location, camera model and capture time. See exactly what leaks before you share it.

GPS Stripping

Removes the GPS IFD with latitude and longitude from JPEG EXIF. The extension and coordinate tags are gone at the byte level.

No Re-encode, No Quality Loss

Rewrites the container and drops the metadata segments. Pixel data is copied byte-for-byte — a photo stays a photo, just without the hidden payload.

Verified by Self-Check

--self-check builds a synthetic image with EXIF, GPS and comments, strips it, and asserts nothing survived.

Quick Start

  1. pip install photo-metaclean — zero dependencies, Python standard library only.
  2. photometaclean photo.jpg --verbose — see what's hidden in your photo.
  3. photometaclean photo.jpg --clean — write a sanitized copy as photo_clean.jpg.
  4. photometaclean --self-check — verify the tool works on your machine.
